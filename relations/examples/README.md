# Example pairs, one per relation

Base motif: `essen/erk30/626/3` (Essen collection) wherever the relation applies to it; otherwise the first motif it applies to. Open the `.musicxml` files in MuseScore.

| File | Relation | B is |
|---|---|---|
| `01_repeat.musicxml` | repeat | A again, note for note |
| `02_octave_up.musicxml` | octave_up | A an octave higher |
| `03_octave_down.musicxml` | octave_down | A an octave lower |
| `04_seq_up_1.musicxml` | seq_up_1 | A moved up one scale step (diatonic sequence) |
| `05_seq_up_2.musicxml` | seq_up_2 | A moved up two scale steps |
| `06_seq_up_3.musicxml` | seq_up_3 | A moved up three scale steps |
| `07_seq_down_1.musicxml` | seq_down_1 | A moved down one scale step |
| `08_seq_down_2.musicxml` | seq_down_2 | A moved down two scale steps |
| `09_seq_down_3.musicxml` | seq_down_3 | A moved down three scale steps |
| `10_real_up.musicxml` | real_up | A moved up 1-5 semitones exactly (real transposition), leaving the key |
| `11_real_down.musicxml` | real_down | A moved down 1-5 semitones exactly, leaving the key |
| `12_inversion.musicxml` | inversion | A's intervals mirrored about its first note, in scale steps |
| `13_retrograde.musicxml` | retrograde | A backwards, pitches and rhythm |
| `14_retro_inversion.musicxml` | retro_inversion | A mirrored and backwards |
| `15_augmentation.musicxml` | augmentation | A in notes twice as long |
| `16_diminution.musicxml` | diminution | A in notes half as long |
| `17_rhythm_new.musicxml` | rhythm_new | A's pitches in another motif's rhythm |
| `18_pitch_new.musicxml` | pitch_new | A's rhythm with another motif's pitches |
| `19_mode_change.musicxml` | mode_change | A in the parallel mode (major <-> minor) |
| `20_ornament.musicxml` | ornament | A decorated with passing tones and neighbor-note turns |
| `21_reduction.musicxml` | reduction | A with its decorations removed (the inverse of ornament) |
| `22_fragment.musicxml` | fragment | A's first bar twice, the second time a step higher or lower |
| `23_opening_kept.musicxml` | opening_kept | A's first bar with a new second bar that doesn't end on the tonic |
| `24_ending_kept.musicxml` | ending_kept | a new first bar followed by A's second bar |
| `25_consequent.musicxml` | consequent | A ends away from the tonic; B keeps A's first bar and closes on the tonic |
| `26_unrelated.musicxml` | unrelated | a motif from another tune, in the same key and register |
